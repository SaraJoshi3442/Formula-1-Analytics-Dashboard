# 🏎️ Formula 1 Dashboard | Power BI

An interactive Power BI dashboard built to analyze Formula 1 racing data through dynamic visualizations and drill-through functionality.

## 📊 Features

- Interactive F1 performance dashboard
- Driver and team analysis
- Race statistics visualization
- Slicers and filters for data exploration
- Drill-through page for detailed insights
- KPI and comparative performance tracking

## 🛠️ Tools Used

- Power BI Desktop
- Data Visualization
- Data Modeling
- DAX Measures

## 📂 Dashboard Pages

### Dashboard
- Overview of Formula 1 statistics
- Interactive charts and KPIs
- Driver and team performance analysis

### Drill Through
- Detailed analysis of selected drivers/races
- Deeper insights through filtered visualizations
